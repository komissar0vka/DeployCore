# DeployCore · редизайн интерфейса

## План рефакторинга

1. Выделить оболочку, навигацию, верхнюю панель и связанные с ними маршруты интерфейса.
2. Собрать общие компоненты и дизайн-токены, сохранить выбор темы и раздавать Inter локально.
3. Сопоставить блоки дашборда с действующими API, затем перевести рабочие страницы на единые компоненты и состояния.
4. Проверить сборку и основные сценарии в Chromium, отдельно проверить действующий контракт в изолированном Compose-проекте.

## Реализация

- `apps/web/src/console-shell.tsx` содержит AppShell, Sidebar и Topbar. На широком экране sidebar фиксирован и имеет ширину 260 px. На мобильном открывается выдвижная панель. Поддерживаются прежние маршруты, глобальный поиск, уведомления, профиль и выбор темы.
- `apps/web/src/design.tsx` содержит PageHeader, StatCard, StatusBadge, DataTable, SearchInput, EmptyState, LoadingSkeleton, ConfirmDialog, DeviceCard, ActivityFeed и QuickAction. Палитра и общая типографика находятся в `style.css`. Inter поставляется с веб-сборкой, включая кириллический набор.
- Дашборд использует `/devices/summary` для численности и состояния компьютеров, версий агентов, событий и предупреждений. Нижняя строка показывает действующие проверки API и PostgreSQL и версию из настроек. Каталог, очередь и история онлайн ещё отсутствуют в API, поэтому их блоки показывают статус разработки или отсутствие истории.
- Переработаны список и карточка устройств, снимки инвентаризации, развёртывание Windows Agent, управление пользователями, аудит, настройки, вход и мастер первичной настройки. Будущие разделы отмечены в меню и при открытии.
- Backend, OpenAPI, миграции, регистрация агентов и правила авторизации сохранены. Фиктивные данные используются только перехватчиками в браузерной проверке.

## Проверка и запуск

Соберите frontend командой `npm ci && npm run build` в `apps/web`. Для проверки рабочего HTTP-контракта с временной базой выполните `deploy/scripts/smoke.sh` из корня проекта. Скрипт поднимает отдельный Compose-проект с HTTPS на локальном порту 18443. Установка на сервере выполняется по README.

Интерфейс опубликован на рабочей панели DeployCore на порту 8444. Пересозданы веб-контейнер и API DeployCore с поддержкой сортировки. Контейнер PostgreSQL, схема БД, FlipHunter и n8n сохранены. По HTTPS проверены новые веб-ресурсы, OpenAPI и readiness.

## Результаты

- TypeScript и Vite собрали веб-приложение. Прошли 14 backend-тестов.
- Chromium проверил рабочие и будущие разделы, ширину sidebar, смену и сохранение темы, вход и мастер, формы пользователя и токена, поиск и сортировку, мобильные карточки и таблицу, права Viewer и состояния загрузки, ошибки и пустого списка. Использованы экраны шириной 1440, 360 и 320 px.
- Изолированный Compose подтвердил HTTPS, OpenAPI, сборки Windows Agent, регистрацию, сессии, роли и восстановление PostgreSQL после перезапуска.
